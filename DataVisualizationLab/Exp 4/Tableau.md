Experiment No. 4  Introduction to Tableau and Installation

Aim:
To study Tableau in detail, understand its features, products, interface, data concepts and visualization workflow, and install Tableau Public for creating interactive visualizations.

Introduction to Tableau:
Tableau is a visual analytics and business intelligence platform used to connect, explore, analyze and communicate data through interactive visualizations. It is designed to transform data into charts, graphs,maps, dashboards and stories that can be explored by users.
The main idea behind Tableau is visual analysis. Instead of writing lengthy programs for every graph,users can select fields and drag them into different parts of the Tableau workspace. Tableau then creates a visual representation based on the selected dimensions, measures and chart type. This makes it possible to explore data quickly and interactively.
Tableau is useful throughout the data analysis workflow. A user can connect to a source, inspect the data, prepare the data, create worksheets, apply filters, build dashboards and finally communicate the findings through a story. Tableau therefore combines data connection, visual exploration, analysis and presentation in one environment.
Tableau is used in business intelligence, education, finance, marketing, operations, human resources, healthcare analytics and many other domains. It is particularly useful when the objective is to communicate patterns and insights to people who may not have programming or statistical expertise.

Objectives of Using Tableau: 
• Convert raw data into understandable visual information.
• Explore datasets interactively.
• Identify trends, patterns and relationships.
• Compare categories and measures.
• Analyze geographical information.
• Build dashboards containing multiple visualizations.
• Present analytical findings as a logical story.

Important Tableau Products:

2. Tableau Public: A free platform for creating and publicly sharing visualizations. It is useful for students, learning and portfolios.

Tableau Data Concepts:

Dimensions:
Dimensions are generally descriptive fields that define categories or groups. Examples include Product,Category, Region, City, Department and Customer. A dimension can be used to divide a visualization intomeaningful categories.
Measures:
Measures are generally numerical fields that can be aggregated. Examples include Sales, Profit, Quantity, Cost and Salary. Tableau can calculate SUM, AVG, MIN, MAX, COUNT and other summaries for measures.
Discrete Fields:
A discrete field creates separate headers or categories. It is useful when the user wants to compare distinct values such as individual regions or product categories.
Continuous Fields:
A continuous field generally creates an axis with a range of values. Continuous measures are useful for visualizing trends, distributions and numerical relationships.
Data Types:
Tableau recognizes common data types such as text, numbers, dates, date-times, Boolean values and
geographical roles. Correct data types are important because Tableau uses them to determine how fields can be analyzed.

Tableau Interface:

Data Pane:
The Data pane lists data sources and fields available in the workbook. Fields are commonly organized into dimensions and measures. Users drag these fields to the worksheet.
Rows Shelf:
The Rows shelf controls the vertical structure of a worksheet. Placing a field on Rows can create a vertical axis or a set of row headers.
Columns Shelf:
The Columns shelf controls the horizontal structure. A categorical field on Columns can create separate headers, while a numerical field can create an axis.
Marks Card:
The Marks card controls visual properties. It includes Color, Size, Label, Detail, Tooltip and Shape. These options allow the user to encode additional information in the visualization.
Filters Shelf:
The Filters shelf restricts the data shown in the view. Filters can be applied to dimensions, measures and dates.
Pages Shelf:
The Pages shelf can show different subsets of a field progressively. It can be useful for observing changes across time or categories.
Show Me:
Show Me provides visualization choices based on selected fields. It helps beginners quickly choose suitable chart types.
Worksheet:
A worksheet is an individual analytical view. Examples include a bar chart, line chart, map or scatter plot.
Dashboard:
A dashboard is a collection of worksheets arranged together. It provides a consolidated view and can contain filters, legends, text and other interactive elements.
Story:
A story is a sequence of worksheets or dashboards used to communicate a series of insights.

Types of Tableau Visualizations:

Bar Chart:
Bar charts are used to compare values among categories. They are suitable for comparing sales by
product, marks by subject or quantity by region.
Line Chart:
Line charts connect observations and are commonly used for trends over time. They are useful for monthly sales, yearly growth and other ordered data.
Pie Chart:
Pie charts divide a circle into sectors to show proportions. They are most useful when there are only a small number of categories and the categories represent parts of a meaningful whole.
Scatter Plot:
Scatter plots represent pairs of numerical observations. They are useful for studying relationships such as Sales versus Quantity or Study Hours versus Marks.
Maps:
Tableau can use geographical fields to create maps. Maps are useful for comparing values across cities,states, countries or other geographic regions.
Heat Map:
A heat map uses visual intensity to represent values in a matrix-like arrangement. It can be used to identify high and low values quickly.
Treemap:
A treemap represents hierarchical or part-to-whole data using nested rectangles. The size of a rectangle can represent a measure while color can represent another field.
Histogram:
A histogram divides numerical values into bins and displays their frequencies. It is useful for understanding distributions.

Filters and Interactivity:

Filters are an important part of Tableau’s interactive analysis. A user can filter by category, region, date, customer or another field. When a dashboard contains several worksheets, filters can sometimes be applied across multiple views. This allows users to ask questions interactively without rebuilding the visualization.
Tooltips provide additional information when the user moves the pointer over a mark. Highlighting can make selected categories easier to compare. Parameters can allow users to change values or analytical choices interactively.

Calculated Fields: 
Calculated fields allow users to create new values from existing fields using expressions. They are useful for derived measures such as profit ratio, growth percentage, classification and other analytical metrics.

Dashboards:
A dashboard combines multiple worksheets in a single screen. A typical dashboard can contain:
• KPI or summary values.
• Bar chart.
• Line chart.
• Map.
• Filters.
• Legends.
• Text descriptions.
A good dashboard should have a clear purpose, logical layout, readable labels and consistent formatting. Too many charts or unnecessary decorative elements can make a dashboard difficult to understand.

Stories:
Tableau Stories are useful when the analysis needs a sequence of explanations. For example, a story
can first show overall sales, then compare categories, then analyze regions and finally show a relationship between quantity and sales. Captions can be added to explain the insight at each story point.
