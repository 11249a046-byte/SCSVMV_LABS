Experiment No. 5 Connecting to Data and Preparing Data for Visualization in Tableau

Aim:
To connect Tableau to a data source and prepare the data for creating visualizations.

Description:
Data preparation is the process of loading, checking, cleaning and transforming raw data before
visualization. Clean and correctly formatted data helps Tableau produce accurate charts and meaningful insights.

Uses:
• Removing duplicate records.
• Detecting missing values.
• Converting data into appropriate types.
• Preparing datasets for visualization.
• Improving data quality and accuracy.

Algorithm:
1. Open Tableau Public.
2. Select the required data source.
3. Import the dataset.
4. Verify the imported data.
5. Perform basic data preparation.
6. Save the workbook.
