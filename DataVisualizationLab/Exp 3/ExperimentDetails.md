Experiment No. 3 Basic Visualization in R

Aim:
To create and understand different basic graphs and visualizations using R programming.

Description:
R is a programming language and environment widely used for statistical computing, data analysis
and visualization. It contains many built-in functions for creating graphs and also supports advanced packages such as ggplot2. The base R graphics system is especially useful for learning fundamentalvisualization concepts because common graphs can be created with short programs.
Visualization in R allows an analyst to explore data before performing detailed statistical analysis. A line graph can show changes across an ordered sequence, a bar chart can compare categories, apie chart can display proportions, a scatter plot can show relationships between numerical variables,and a histogram can show the distribution of numerical observations.
In this experiment, five basic visualization programs are implemented using base R. Each program
demonstrates a different graph type. These programs help students understand how vectors are cre-
ated, how graph functions receive data, and how titles and labels are added. The same visualization
principles can later be applied to larger datasets and advanced R packages.

Uses:
• Statistical data exploration.
• Visual comparison of categories.
• Trend analysis.
• Relationship analysis.
• Distribution analysis.
• Presentation of analytical results.

Algorithm:
1. Create the required R vectors.
2. Select a suitable visualization function.
3. Pass the data to the graph function.
4. Add title and axis labels.
5. Execute the R program.
6. Observe and interpret the graph.

Libraries / Functions Used:
• plot() – creates line and scatter plots.
• barplot() – creates bar charts.
• pie() – creates pie charts.
• hist() – creates histograms.
• Base R – provides these functions without requiring an external package.

Result:
Thus, five basic visualizations—line graph, bar chart, pie chart, scatter plot and histogram—were
successfully created using R programming.
