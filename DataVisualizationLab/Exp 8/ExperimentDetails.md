Experiment No. 8 Data Visualizations in Tableau: Drawing Charts, Graphs, and Data Mapping

Aim:
To create various charts, graphs, and data maps using Tableau for effective data visualization.

Description:
Different chart types are useful for different analytical purposes. Bar charts compare categories,
pie charts show proportions, line charts show trends, and maps represent geographical information.
Tableau provides a simple interface for creating these visualizations.

Uses:
• Comparing categories using bar charts.
• Showing percentage distributions using pie charts.
• Displaying trends using line charts.
• Representing geographical information using maps.
• Communicating business insights clearly.

Algorithm:
1. Open Tableau Public.
2. Connect to the dataset.
3. Drag required fields to Rows and Columns.
4. Select an appropriate chart type.
5. Customize the visualization.
6. Analyze and save the visualization.
