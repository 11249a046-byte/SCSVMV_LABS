Experiment No. 2   Basic Visualization in Python

Aim:
To create and understand different basic graphs and visualizations using Python and the Matplotlib
library.

Description:
Python is one of the most widely used programming languages for data analysis and visualization.
Its visualization ecosystem contains libraries that make it possible to convert numerical and categorical data into meaningful graphical representations. 
Matplotlib is a fundamental visualization library
because it provides functions for creating and customizing a wide range of static graphs.
Different graphs communicate different types of information. A line chart is suitable for showing a
trend or change in values. A bar chart is useful when separate categories have to be compared.
A pie chart represents the relative contribution of categories to a whole. A scatter plot is useful
for studying the relationship between two numerical variables. A histogram shows the frequency
distribution of numerical observations.
In this experiment, five independent visualization programs are developed. The programs use small
datasets so that the plotting logic is easy to understand. Each program contains a title and appropriate axis labels. These examples provide the basic knowledge required for creating more advanced visualizations from real-world datasets.

Uses:
• To understand data visually.
• To identify trends and patterns.
• To compare different categories.
• To understand distributions.
• To study relationships between numerical variables.
• To communicate analytical results clearly.

Algorithm:
1. Import the required Matplotlib module.
2. Prepare suitable data.
3. Select a visualization according to the purpose of the analysis.
4. Create the graph.
5. Add title and axis labels.
6. Display the visualization.
7. Interpret the result.

Libraries / Functions Used:
• Matplotlib: Main Python library used for creating visualizations.
• pyplot: Matplotlib module that provides plotting functions such as plot(), bar(), pie(),
scatter() and hist().

Result:
Thus, five basic visualizations—line chart, bar chart, pie chart, scatter plot and histogram—were
successfully created using Python and Matplotlib.
